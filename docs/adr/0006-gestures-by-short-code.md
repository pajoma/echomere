# Gestures are sent through a short code that expires with the stop

Gestures can't be sent from the screensaver, because it closes at the first key press. Anyone watching a
visiting whale sends them from the web page, using a short code the screensaver shows. The code is valid only
for that 24-hour stop, so photos of a screen go stale. Each browser can send one gesture per code per hour,
enforced on the server without storing who sent what. We chose this over a fixed link per whale because the
code is visible to everyone who walks past the screen.
