# Every town is a cove

A cove is a town from the GeoNames list of places with more than about 15,000 inhabitants, not an
installation of the screensaver, and every town on the list is a cove whether or not any creator lives there.
Coves with creators who are still looking are watched; the rest are quiet. We chose this because there is one
whale per creator but only five places per cove: if only populated towns were coves, the busiest places would
always be full and most whales would wait unseen in the deep sea. Whales prefer watched coves and go to quiet
ones only when the watched coves nearby are full. The browser picks the nearest town from the list itself, so
coordinates never leave the device.
