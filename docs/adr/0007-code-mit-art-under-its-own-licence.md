# Code is MIT; art has its own licence

Echomere's code is under the MIT licence, but the whale models are not: they are adapted from scientifically
accurate models (DigitalLife3D's southern right whale, neurodolphin's orca) that are only available under
CC BY-NC 4.0, and no realistic whale model with a more permissive licence was found. So art assets live in
their own folders with their own licence file and credits, separate from the code. We accept the
consequence: nobody, including us, may sell a build that contains these whales, which is fine for a hobby
project that is free to download. Store-licensed models (Sketchfab Standard, TurboSquid, CGTrader) stay out
entirely, because they forbid putting the files in a public repository.
