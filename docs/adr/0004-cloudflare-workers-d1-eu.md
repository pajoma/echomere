# Backend on Cloudflare Workers and D1, in an EU region, self-hostable

The backend runs on Cloudflare Workers with D1 in an EU region, instead of a small VPS or peer-to-peer
between screens, because a hobby project needs something with nothing to maintain, and clients check in only
rarely (on start, then about once an hour). Every cove is personal data under GDPR, so data stays in the EU.
We accept being tied to one provider, and keep the backend small enough that anyone can run their own
instance from the open-source code.
