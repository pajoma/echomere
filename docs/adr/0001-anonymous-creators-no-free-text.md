# Anonymous creators, no free text, no moderation

Echomere has no accounts, no names and no free text: a creator is known only by their cove and 2 or 3 traits
from a fixed list, the whale's look comes from fixed options, and the only way to react is one of three fixed
gestures. Ownership is a secret key on the device, opened in the web page through a bookmarked link with the
key in the URL fragment. We chose this over accounts and friend groups because a hobby project can't carry
moderation work, and because strangers who connect only through traces is the point of the project (the
"Death Stranding" feeling). Consequence: a lost key means a lost whale, so the web page offers a key backup.
